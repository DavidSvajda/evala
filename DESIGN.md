# Evala visual system

User-pinned compact vertical bar beside the board. Operate mode: read evaluation without opening a panel.

The interface borrows from quiet chess clocks: graphite #191b1a, warm white #f2f0e9, muted brass #d5b77a, secondary text #b2b6ad. A clear midpoint marker separates neutral from changing advantage. The white segment grows for positive scores, the black segment for negative scores. Orientation follows the board; score always remains from White's perspective.

Manrope is bundled locally. Tabular numerals for scores, depth and speed. Small SVG stroke icons, visible keyboard focus, reduced-motion support. Settings use one vertical form, restrained separators and no decorative cards. The extension bar has no persistent wide panel. Controls live in the popup or an anchored settings popover.

The study surface is Operate mode in the same visual world: a library at left, a primary interactive board and evaluation graph in the center, and review controls, results, lines and move notation at right. Desktop height is bounded by the viewport; the center includes all navigation, graph and export actions. Only lists scroll. Settings use a dismissible side drawer. The player overview is a separate workspace, with filters, result tables, phase comparisons and links back to training positions. On narrow screens the library is toggled and the results follow the board vertically. Imported user content drives all names, dates and results. Move badges use conventional chess annotations with semantic colors. No fabricated benchmark or official Chess.com badge claims.

Version 1.3 starts hosted visitors on a single player form. A completed report collapses its setup to one editable row so results lead. The manually selected games define every statistic in that report and survive a reload. The board now uses viewport height minus 252px for its square edge, with the small graph directly below and export/delete in the game menu. At 1366×768 it is approximately 516px square, compared with 422px in 1.2. Functional text has an 11px floor. Evaluation fill animates with a transform. Arrow navigation is captured at window level and stays available when toolbar controls have focus; text editing and settings fields retain normal keyboard behavior.

Version 2.0 expands Evala into a personal training workspace with discrete addressable routes (`home`, `games`, `analysis`, `puzzles`, `insights`, `settings`, `account`). A collapsible 212px navigation rail toggles via header controls, allowing the primary analysis board to maximize viewport usage. Puzzles introduce individual calibrated Elo ratings from the stratified CC0 Lichess bank alongside uncalibrated personal mistake positions. Full bilingual UI (Czech and English) is supported without build-step overhead via dynamic DOM mutation translation. Guest mode preserves complete offline IndexedDB privacy; signing in connects durable Azure Blob document storage for multi-device library and training synchronization.
